# AgentManifest Schemas

This directory contains canonical JSON Schemas for the experimental AgentManifest specification package.

| File | Purpose |
| --- | --- |
| [`agent-manifest.v0.1.schema.json`](./agent-manifest.v0.1.schema.json) | Canonical JSON Schema for AgentManifest `0.1-draft`. |

The v0.1 schema uses JSON Schema Draft 2020-12 and keeps `additionalProperties: true` for forward-compatible experimentation.
