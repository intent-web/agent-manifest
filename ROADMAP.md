# Roadmap

AgentManifest is experimental. The roadmap below describes intended draft direction, not a standards commitment.

## 0.1

- Static discovery.
- Example manifests.
- Canonical schema.
- Validation documentation.

## 0.2

- OpenAPI examples.
- MCP examples.
- Validator CLI.

## 0.3

- Consent token model.
- Action result envelope.
- Policy examples.

## 1.0

- Stable schema.
- Compatibility rules.
- Clear extension and deprecation process.
