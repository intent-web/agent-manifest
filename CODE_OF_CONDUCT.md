# Code of Conduct

This project follows a concise Contributor Covenant-style code of conduct.

## Our Standards

Participants are expected to be respectful, constructive, and focused on improving the specification. Harassment, personal attacks, sustained disruption, or discriminatory behavior are not acceptable.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, documentation, and related community channels.

## Enforcement

Maintainers may remove comments, close discussions, block participation, or take other reasonable action to keep collaboration professional and productive.

## Reporting

Report conduct concerns privately to the maintainers. Include relevant links, context, and timestamps where possible.
