# Governance

AgentManifest is currently an experimental open specification. It is not an official RFC or IETF-approved standard.

## Draft Changes

Draft changes should be proposed through issues or pull requests. Significant changes should explain:

- the interoperability problem,
- the proposed behavior or schema shape,
- security and privacy impact,
- compatibility and migration impact,
- examples affected by the change.

## Review Criteria

Maintainers review changes for:

- clarity,
- implementability,
- compatibility with existing examples,
- security and privacy impact,
- validation impact,
- consistency with the specification-oriented tone.

## Manifest Shape Changes

Changes to the manifest shape should update `rfc/SPEC.md`, `rfc/schemas/`, relevant docs, and at least one example.

## Decision Process

During the experimental phase, maintainers may accept changes that improve implementation feedback and reject changes that create unsafe ambiguity, unnecessary complexity, or premature standardization claims.
